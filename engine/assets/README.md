# assets

Contenido del juego por paquetes ([tubería de assets](../../docs/architecture/assets-pipeline.md)). `AssetId` es el nombre estable de un asset (`digimon/agumon/model`) y `PackManifest` lee el `pack.yaml` de cada paquete: id, versión, capa, prioridad y dependencias. El formato del manifiesto también está en [`content/schemas/pack.schema.json`](../../content/schemas/pack.schema.json). `findPacks` encuentra los paquetes de una carpeta de contenido y `VirtualFileSystem` los monta, los apila por capa y prioridad y dice qué fichero gana para cada ID. Lee los ficheros a través de `FileSystem`: `DiskFileSystem` para el disco y `MemoryFileSystem` para los tests. Solo depende de `core`. `decodePng` decodifica un PNG a RGBA de 8 bits con lodepng, para las texturas que lee el motor (el visor de assets del overlay de depuración, por ahora).
