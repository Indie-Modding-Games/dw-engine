# 0002. C++26 with GCC and Clang

- **Status:** Accepted
- **Date:** 2026-10-18

## Context

We want the most recent standard. WG21 finished C++26 in March 2026; its publication by ISO is pending. GCC 16
supports almost all of C++26, Clang supports it partially and MSVC is behind.

## Decision

The project uses **C++26** (`-std=c++26`). It is built with **GCC 16+ and Clang** on Linux, and with **Clang** on
Windows (clang-cl or llvm-mingw). Only the C++26 features supported by all the CI compilers are used.

## Consequences

- We get the recent improvements to the language and the standard library.
- MSVC is not a supported compiler.
- When a CI compiler adds a feature, we can start using it. The list lives in
  [code conventions](../conventions/code.md).

## Alternatives rejected

- **C++23:** more stable, but it is not the most recent and C++26 is already finished.
- **Support MSVC:** it would limit us to what the most lagging compiler supports.
