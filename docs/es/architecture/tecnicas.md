# Catálogo de técnicas

## 1. Objetivo

Recopilar las técnicas existentes en Digimon World como referencia para el rediseño del sistema de combate de DWPF.

El arsenal original cuenta con **56 técnicas distribuidas en 7 especialidades**. Cada técnica dispone de parámetros como potencia, coste de MP, alcance y efectos adicionales.

Esta recopilación servirá como base para analizar, clasificar y posteriormente ajustar las técnicas para el nuevo sistema de combate.

## 2. Estadísticas de las técnicas

|Parámetro|Descripción|
|---|---|
|Power|Potencia base de la técnica.|
|MP|Coste de puntos de magia necesarios para ejecutarla.|
|Range|Alcance de la técnica.|
|Effect|Efectos adicionales, como stun, poison o confuse.|

Los efectos y valores de las técnicas deben verificarse antes de utilizarlos como base definitiva de balance.

## 4. Efectos presentes en el arsenal

|Efecto|Función general|
|---|---|
|Stun|Interfiere o incapacita temporalmente al objetivo.|
|Confuse|Alteración del comportamiento del objetivo.|
|Poison|Aplica daño o deterioro progresivo.|
|Flat|Efecto especial cuyo funcionamiento debe verificarse individualmente.|
|Buff|Mejora temporal de atributos.|

> La descripción exacta, duración, probabilidad y comportamiento de cada efecto deben investigarse individualmente.

### Consideraciones

- Los AP y MP originales corresponden a Digimon World 2.

- Los valores de potencia de DWPF no deben trasladarse directamente desde DW2, ya que ambos sistemas utilizan estructuras de combate diferentes.

- La especialidad Holy y Dark se asigna según la temática y mecánica de la técnica, no necesariamente según la especialidad original de DW2.

- Las técnicas de recuperación, resurrección, invulnerabilidad y drenaje requieren reglas específicas de balance.

- Las técnicas de control deberán tener en cuenta interrupciones, duración, resistencia del objetivo y ventanas de ejecución.

- El catálogo de candidatos no representa técnicas aprobadas. Su objetivo es servir como material de selección para el nuevo arsenal de DWPF.
